# 台前随屏 使用说明

台前随屏 根据外接显示器连接状态切换台前调度，支持 macOS 14 及以上版本。

## 安装与启动

1. 将 台前随屏.app 拖入安装盘中的 Applications 文件夹。升级时先从菜单栏退出旧版，再替换 App。升级前请关闭旧版的“登录时启动”。更换应用标识后的首次运行使用默认设置，请重新开启自动切换和登录启动。
2. 从“应用程序”打开 台前随屏，不要直接在安装盘中运行。
3. 新安装默认暂停。在设置中选择“启用自动切换”；再次启用只记录当前连接情况，不立即改变台前调度。

连接外接屏时关闭台前调度，断开时开启。同一连接状态下，手动调整不会被周期检查覆盖。睡眠期间的插拔不在唤醒后补做。

展开“高级设置”可调整“备用检查间隔”，选项为 1、2、5、10、30 分钟，默认 5 分钟，修改立即生效。它用于补查可能遗漏的系统通知，不影响正常插拔时的切换速度。大部分连接变化由系统事件触发并等待稳定 2 秒后处理。

## 日常使用

- 关闭设置窗口后，App 继续在菜单栏运行。可从菜单栏打开设置、暂停或退出。
- “登录时启动”由 macOS 管理，需要批准时，App 会提供系统设置入口。
- 切换失败时，菜单栏和设置页会提示原因；可自行在系统设置中调整台前调度。App 不会为同一次连接变化反复重试。
- 可通过“查看日志”检查记录；分享日志前请检查是否包含本机路径。

## 兼容性与签名状态

此构建采用本地临时签名，未经 Apple 公证；其他 Mac 可能阻止打开。不要关闭 Gatekeeper 或系统安全保护。正式分发流程见 [分发说明](docs/DISTRIBUTION.md)。

台前调度控制依赖系统内部偏好，并可能重载 Dock。macOS 更新后可能失效；App 显示设置已提交，不代表所有系统上的界面效果均已验证。虚拟显示器、Sidecar 和 AirPlay 可能被计为外接屏。

## 卸载与数据

先关闭“登录时启动”，从菜单栏退出，再将 App 移到废纸篓。设置和日志仅保存在本机；详情见 [隐私说明](docs/PRIVACY.md)。
