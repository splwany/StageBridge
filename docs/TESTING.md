# 0.1.0-beta.1 测试记录

日期：2026-09-27。实际机器：Apple M2、macOS 15.6。
构建：Apple Swift 6.2，macOS 15.5 SDK，最低目标 macOS 14.0。

已完成：

- arm64 和 x86_64 编译成功，lipo 生成通用二进制。
- 9 项状态策略断言通过：首次启动、重复状态、连接、断开、暂停、恢复、未知状态和唤醒基准。
- 在本机真实打开 App，确认固定窗口、无绿色缩放按钮、状态显示、菜单和退出功能。
- UI 调整备用间隔 60→30→60，状态文字立即更新；暂停后重新启用成功。
- 退出后重新打开，保留启用状态、60 秒设置和登录启动选项。
- 原型迁移按钮实际执行：旧 LaunchAgent 卸载并禁用，plist/py 已归档，旧偏好导入成功。
- SMAppService 登录项在本机注册成功；尚未实际注销/重登验证。
- 本地签名校验通过。Info.plist 与 Xcode project.pbxproj 语法检查通过。

- 原生 Xcode Build/Archive：本机只有 Command Line Tools，本轮通过命令行完成构建，未在完整 Xcode 中构建。
- 真正的登录启动、系统设置撤销权限、从 DMG 安装到干净 Mac、卸载。
- Developer ID 签名、公证、Gatekeeper 首次下载体验：尚无可用签名身份，均未执行。

已知兼容性：Stage Manager 控制使用未公开的系统偏好。接口改变时应暂停自动控制并发布修复，不能宣称 App Store 合规或所有系统通用。
