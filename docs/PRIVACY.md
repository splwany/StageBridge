# 隐私说明

台前随屏（StageByScreen）在本机读取在线显示器是否包含非内置显示器，并按用户选择修改台前调度偏好。不会读取屏幕内容、文件内容、键盘输入或个人账号信息。不含分析 SDK、广告或遥测。

本机保存：启用状态、备用检查间隔，以及动作/错误日志。日志不记录显示器序列号或显示器名称。命令失败诊断可能包含本机路径，分享日志前请检查内容。日志达到 512 KB 后保留一份旧日志。

可通过设置窗口打开日志。退出 App 后可删除 `~/Library/Logs/StageByScreen`。卸载前请先关闭“登录时启动”并退出 App。

## 软件更新网络请求

带更新组件的版本默认每天通过 HTTPS 访问 GitHub Release 的签名 appcast；下载更新时连接 GitHub 及其分发域名。服务器可获得 IP 地址及正常请求信息（包括客户端 User-Agent）；不上传屏幕内容、偏好或日志，关闭 Sparkle 系统信息统计。高级设置可关闭自动检查；手动检查仍会联网。

Sparkle 在本机保存检查时间、更新偏好和下载缓存。用户确认后下载、验证并安装更新；安装权限不足时可能由系统请求授权。更新签名验证不能替代 Apple 公证。
